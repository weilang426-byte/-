

定义两个变量，对应唯一的一个按键，表示是否被按下，以及上次按下的时间，默认为0

extern volatile uint8_t key_flag ;
extern volatile uint32_t key_last_tick;



回调函数中先判断是哪个按键触发的中断，然后非阻塞式消抖：比如now=200，然后传给lasttick，这中间如果有抖动，比如203ms抖动了一次
此时now-200=3<20，不认为这是一次触发，而是一次抖动，所以实际上是两次被 EXTI 检测到的有效事件之间，至少间隔 20 ms。

第一次按下之后，按键不会被忽略，同时后面的抖动不会进入if语句，除非间隔大于了20ms

void HAL_GPIO_EXTI_Callback(uint16_t GPIO_Pin) {
  uint32_t now;
  if (GPIO_Pin == Button_K1_Pin) {
    //K1按下并消抖
     now = HAL_GetTick();
    if (now-key_last_tick >=20) {
      //执行逻辑
      key_last_tick = now;
      key_flag = 1;
    }
  }
  else if (GPIO_Pin == Button_K2_Pin) {
    //K2按下

  }
  else if (GPIO_Pin == Button_K3_Pin) {
    //K3按下

  }
  else if(GPIO_Pin == Button_K4_Pin) {
    //K4按下


  }
}
